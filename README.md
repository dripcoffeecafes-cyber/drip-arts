# drip-arts

Artes finais da Drip Coffee Label hospedadas para o Metricool (links raw com hash do commit).

Organização: AAAA-MM/<pasta-da-peça>/ para feed e Reels; AAAA-MM/stories/ para Stories.

Histórico: tudo o que foi produzido de 28/09 a 29/09/2026 foi fase de teste, nada publicado,
e foi excluído em 29/09/2026 a pedido do responsável (recuperável no commit 84e7cd3).

Versões: cada pasta guarda só a versão que vale (o arquivo é sobrescrito a cada versão nova e as anteriores ficam no histórico do Git). Material substituído por um conjunto novo vai para _arquivo/ dentro da pasta do mês (ex.: 2026-10/_arquivo/mercado-livre). Cópias com versão no nome (capa_v11 etc.) ficam no Google Drive, com as anteriores em _arquivo/ de cada pasta.
